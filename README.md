# The Corner Loaf

A mobile-first, accessible neighbourhood bakery website for The Corner Loaf in East Legon, Accra, built with plain HTML, CSS, and JavaScript (no framework or backend).

**Live website:** [The Corner Loaf on GitHub Pages](https://samuel-attu.github.io/the-corner-loaf/)
